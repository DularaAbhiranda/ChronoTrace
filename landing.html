// WEB INTERFACE

Beyond the CLI, ChronoTrace ships a full React application — an interactive timeline browser with filtering, export, and compare capabilities.

01

Interactive Timeline

Zoomable, pannable vis.js timeline with color-coded lanes per source. Scroll to zoom, drag to pan, click any event to inspect its full detail.

02

Filter Panel

Filter by source, event type, date range, or keyword simultaneously. Active source badges distinguish passive results from live probe data.

03

Live SSE Progress

Server-Sent Events stream individual scan results as connectors finish. Watch the timeline populate in real time — no polling, no page refresh.

04

Export & Compare

Export the full result or a filtered slice as JSON or CSV. Compare mode lets you overlay two domain timelines side-by-side for diff analysis.

05

API Key Vault

Optional enrichment sources (Shodan, VirusTotal, HIBP, SecurityTrails) activate once you add their API keys — stored only in your browser.

06

Scan History

Every completed scan is persisted. Reload past jobs instantly without re-running them. Navigate between jobs from the history panel.

// CLI CAPABILITIES

[01]

Passive Aggregation

Wayback Machine CDX, crt.sh CT logs, RDAP registration, and live DNS — all queried in parallel, all in ~90 seconds. The target never sees a packet from you.

  • + Up to 5,000 historical URLs per scan
  • + Every TLS cert ever issued for the domain
  • + Subdomain enumeration via CT log traversal
  • + Retry-with-backoff on flaky APIs
[02]

Active Probing

Seven Tier-2 modules behind a hard authorization gate: live HTTP probe, TLS handshake, service-aware port scan, AXFR attempt, well-known harvesting, directory probe.

  • + Top-20 or full 1–65535 port scan
  • + Banner grab with service-aware signatures
  • + HTTP security header audit
  • + ~150 high-value path probing
[03]

Pipe-Friendly Output

Rich-rendered terminal tables by default. JSON or CSV for downstream tooling. Quiet and no-color modes for scripts. Built to chain into nuclei, nmap, ffuf, Burp.

  • + chronotrace target.com --json | jq
  • + --csv for Excel/spreadsheet imports
  • + --quiet --no-color for cron jobs
  • + Standard exit codes (0 / 1 / 2 / 3)
[04]

Authorization-Gated

Active modules require you to retype the target domain before sending any live traffic. -y flag available for scripted authorized use only. Every scan is audit-logged.

  • + Interactive confirmation prompt by default
  • + Per-module red ACTIVE badge in web UI
  • + CFAA / GDPR / Computer Crime Act aware
  • + Scope confirmation modal in the web UI

// DATA SOURCES

Four free sources run automatically. Enrichment sources activate once you supply API keys. All sources are queried concurrently via async workers.

🕰️ Wayback Machine FREE

Internet Archive CDX API. Historical snapshots with permanent citation URLs. Up to 5,000 events per scan.

🔒 crt.sh FREE

Certificate Transparency log search. Every TLS cert ever issued — exposes subdomains, their first-seen dates, and issuers.

📋 RDAP FREE

Registration Data Access Protocol. Registrar, creation / expiry dates, nameservers, and registrant history.

🌐 DNS (live) FREE

A, AAAA, MX, TXT, NS, CNAME record resolution. Anchors current infrastructure state to the historical timeline.

🔍 Shodan API KEY

Internet-wide scan data: open ports, service banners, exposure history, and infrastructure fingerprints.

🛡️ VirusTotal API KEY

Aggregated threat intelligence: malware associations, URL verdicts, historical detections, vendor analysis.

🚨 HIBP API KEY

Have I Been Pwned breach records associated with the domain — credential leak history and affected accounts.

📡 SecurityTrails API KEY

Historical DNS records and IP history. Tracks IP transitions, nameserver changes, and past infrastructure configs.

// INSTALL

One-line install via pipx. Puts chronotrace in your $PATH alongside nmap, sqlmap, and hydra.

kali · ubuntu · macos 
# clone, install, verify
$ sudo apt install -y pipx jq
$ pipx ensurepath
$ git clone https://github.com/DularaAbhiranda/ChronoTrace.git
$ cd ChronoTrace
$ pipx install ./backend
$ chronotrace --version
chronotrace 1.0.0
windows · powershell 
PS> python -m pip install --user pipx
PS> python -m pipx ensurepath
PS> git clone https://github.com/DularaAbhiranda/ChronoTrace.git
PS> cd ChronoTrace
PS> pipx install .\backend
PS> chronotrace --version

// RECIPES BY ROLE

Pick the scenario closest to what you're doing. Full instructions in the 50-page User Guide.

01

Curious explorer

chronotrace example.com

Safe passive scan against any public target. No active traffic, zero risk.

 02

Site owner / DevSec

chronotrace mysite.com --active -y

Audit your own domain: forgotten subdomains, missing security headers, exposed paths.

 03

Authorized pentest

chronotrace target.com --full -y -o recon.json

Complete external surface map in ~10 min. Feed JSON into nuclei, ffuf, or Burp.

 04

Brand-abuse investigator

chronotrace fake-brand.tld --only wayback,crt_sh,rdap

Passive evidence collection on phishing lookalikes. RDAP date + first CT cert proves intent.

 05

Incident responder

chronotrace affected.com --json -o ir-timeline.json

Reconstruct attacker infra timeline. CT first-seen dates expose provisioning timestamps.

 06

Journalist / researcher

chronotrace newssite.com --only wayback

What did this site say before the edit? Wayback CDX with permanent citation URLs.

// RESPONSIBLE USE

ChronoTrace is built for authorized use only: domains you own, domains you are contracted to assess, or public threat-intelligence research with a clear legitimate purpose. Active modules send live requests that appear in target server logs and IDS alerts. Unauthorized reconnaissance may violate the Computer Fraud & Abuse Act, GDPR Article 32, the Sri Lanka Computer Crime Act No. 24 of 2007, and equivalent laws in your jurisdiction.

> The authorization prompt is a hard gate. It cannot be bypassed without the -y flag. Use -y only when you have verified written authorization for the target.
