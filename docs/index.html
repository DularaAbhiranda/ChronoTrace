> Domain History · Certificate Transparency · Active Recon

A pip-installable Kali-style command-line tool that consolidates Wayback Machine, crt.sh, RDAP, live DNS, and seven opt-in active modules into one chronological timeline. Built for security researchers, authorized pentesters, brand-abuse investigators, and incident responders.

// CAPABILITIES

[01]

Passive Aggregation

Wayback Machine CDX, crt.sh Certificate Transparency, RDAP registration, live DNS — all in parallel, all in 90 seconds. The target never knows you looked.

  • + Up to 5,000 historical URLs per scan
  • + Every TLS cert ever issued for the domain
  • + Subdomains derived from CT logs
  • + Retry-with-backoff on flaky APIs
[02]

Active Probing (Opt-in)

Seven Tier-2 active modules behind a hard authorization gate. Live HTTP probing, real TLS handshake, service-aware port scan, AXFR attempt, well-known harvesting, directory probe.

  • + Top-20 or full 1-65535 port scan
  • + Banner grab with service-aware probes
  • + HTTP security header audit
  • + ~150 high-value path probing
[03]

Pipe-Friendly Output

Pretty Rich-rendered terminal tables by default. JSON or CSV for downstream tools. Quiet and no-color modes for scripts. Designed to chain into nuclei, nmap, ffuf, Burp.

  • + chronotrace target.com --json | jq
  • + --csv for Excel imports
  • + --quiet --no-color for cron jobs
  • + Standard exit codes (0/1/2/3)
[04]

Authorization-Gated

Active modules require explicit confirmation. The default flow asks you to retype the target domain before sending any live traffic. CFAA / GDPR / Sri Lanka Computer Crime Act respected.

  • + Interactive prompt by default
  • + -y flag for scripted use only
  • + Per-module visual distinction (red badge)
  • + Audit log of every scan

// INSTALL

One-line install on Kali / Ubuntu / macOS via pipx. Adds chronotrace to your $PATH alongside nmap, hydra, sqlmap.

kali · ubuntu · macos 
# clone, install, verify
$ sudo apt install -y pipx jq
$ pipx ensurepath
$ git clone https://github.com/DularaAbhiranda/ChronoTrace.git
$ cd ChronoTrace
$ pipx install ./backend
$ chronotrace --version
chronotrace 1.0.0
windows · powershell 
PS> python -m pip install --user pipx
PS> python -m pipx ensurepath
PS> git clone https://github.com/DularaAbhiranda/ChronoTrace.git
PS> cd ChronoTrace
PS> pipx install .\backend
PS> chronotrace --version

// RECIPES BY ROLE

Pick the scenario closest to what you're doing. Full instructions in the 50-page user guide.

01

Curious explorer

chronotrace example.com

Just see what's possible. Run a safe passive scan against any public target.

 02

Site owner

chronotrace mysite.com --active -y

Audit your own domain for forgotten subdomains, missing security headers, exposed paths.

 03

Authorized pentest

chronotrace target.com --full -y -o recon.json --json

Complete external surface map in 10 min. Feed the JSON into nuclei, ffuf, Burp.

 04

Brand-abuse investigator

chronotrace fake-bank.tld --only wayback,crt_sh,rdap,dns

Passive evidence collection on phishing lookalikes. RDAP date + first CT cert proves intent.

 05

Incident responder

chronotrace affected.com --json -o ir-timeline.json

Reconstruct attacker infra timeline. CT first-seen dates show provisioning timestamps.

 06

Journalist / researcher

chronotrace newssite.com --only wayback

What did this site say before the edit? Wayback CDX with permanent citation URLs.

// RESPONSIBLE USE

ChronoTrace is built for authorized use: domains you own, domains you're contracted to assess, or public threat-intelligence research. Active modules send live requests that appear in target server logs and IDS systems. Unauthorized reconnaissance may violate the Computer Fraud & Abuse Act, GDPR Article 32, the Sri Lanka Computer Crime Act, and equivalent laws in your jurisdiction.

> The authorization prompt is a hard gate. It cannot be bypassed without -y. Use that flag only when you are 100% sure about the target.
